# Apex Construction Hub

Crie um site institucional premium para a empresa:

ROBERTO DEUCHER

MÃO DE OBRAS • CONSTRUÇÃO CIVIL

O design deve ser desenvolvido EXCLUSIVAMENTE a partir da identidade visual apresentada na logo da empresa.

IDENTIDADE VISUAL:

A logo possui um símbolo geométrico que combina a representação de uma casa com as letras "RD". Esse elemento deve ser tratado como um símbolo arquitetônico e pode inspirar detalhes gráficos, divisores, molduras e elementos de navegação.

CORES PRINCIPAIS:

AZUL-MARINHO

#20314D

Cor principal da marca. Utilizar em textos importantes, header, botões, elementos estruturais e seções de destaque.

TERRACOTA

#A6593B

Cor de destaque. Utilizar com moderação em linhas, pequenos detalhes, indicadores, hover states e CTAs secundários.

OFF-WHITE

#F7F6F2

Cor principal de fundo.

BRANCO

#FFFFFF

Utilizar para contraste e áreas de respiro.

CINZA CONCRETO

#D9D9D6

Utilizar em backgrounds secundários, divisores e elementos de apoio.

A paleta deve ser predominantemente azul-marinho e off-white, com o terracota aparecendo como detalhe sofisticado.

NÃO UTILIZAR:

- Verde

- Amarelo

- Gradientes chamativos

- Neon

- Preto puro como cor dominante

- Efeitos excessivos

- Estética de construtora popular

- Ícones coloridos genéricos

DIREÇÃO ESTÉTICA:

Criar uma estética inspirada em:

- Arquitetura contemporânea

- Engenharia

- Projetos residenciais de alto padrão

- Materiais naturais

- Concreto

- Pedra

- Madeira

- Linhas arquitetônicas

- Plantas e desenhos técnicos

O resultado deve transmitir:

CONFIANÇA

SOLIDEZ

PRECISÃO

CUIDADO

PROFISSIONALISMO

A interface deve ser elegante, limpa e masculina, mas sem parecer pesada.

TIPOGRAFIA:

Utilizar uma fonte sans-serif contemporânea e sofisticada.

Headlines:

Fonte com peso médio/semibold, caixa normal ou algumas palavras em uppercase.

Body:

Fonte limpa e altamente legível.

Utilizar letter-spacing levemente aumentado em textos institucionais e pequenos labels, inspirado na tipografia da própria logo.

Evitar fontes excessivamente arredondadas, futuristas ou decorativas.

GRID:

Utilizar grid editorial de arquitetura.

Muito espaço negativo.

Seções com:

- textos alinhados

- grandes fotografias

- blocos assimétricos

- linhas finas

- números de seção

- divisores horizontais

Criar sensação de projeto arquitetônico.

HEADER:

Header branco/off-white.

Logo Roberto Deucher no lado esquerdo.

Menu:

INÍCIO

SOBRE

SERVIÇOS

PROCESSO

CONTATO

Botão:

"FALAR PELO WHATSAPP"

O botão deve utilizar azul-marinho, com detalhes terracota discretos.

Ao rolar a página, o header deve permanecer fixo e ganhar uma sombra extremamente sutil.

DETALHES DE INTERFACE

Usar animações extremamente sutis:

- Fade-in ao entrar nas seções

- Imagens reveladas durante o scroll

- Pequenos movimentos de parallax

- Hover elegante nos serviços

- Linhas arquitetônicas aparecendo progressivamente

- Números de seção com animação discreta

NÃO exagerar nas animações.

A sensação deve ser de um site de arquitetura premium.

O terracota deve ser usado como uma assinatura visual, não como uma cor dominante.

Criar elementos gráficos inspirados diretamente no símbolo da logo:

- linhas de telhado

- ângulos geométricos

- divisores

- estruturas semelhantes a plantas arquitetônicas

- formas lineares discretas

IMPORTANTE:

A logo original deve ser utilizada sem alteração ou redesenho.

Não criar uma nova identidade visual.

O site deve fazer o visitante sentir:

"Essa é uma equipe organizada, profissional e confiável para cuidar da minha obra."
